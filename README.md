# c2c-003 · 信息食谱调配师

Vue 3 + TypeScript + Vite 纯前端信息摄入管理工具。用户记录文章、视频、播客、社交媒体和书籍等信息消费，按深度知识、行业动态、技能提升、娱乐消遣、社交信息分类，通过营养金字塔、偏食检测、优化食谱与摄入报告管理信息饮食。数据保存在浏览器 `localStorage`。

## 分层

- 核心层 `src/core`：摄入记录、营养比例、偏食/缺失检测、餐盘评分与食谱建议；`backup.ts` 负责备份文件的导出、校验、旧版本补齐与合并去重
- 端口层 `src/ports`：信息食谱快照仓储接口
- 适配器层 `src/adapters`：浏览器本地存储实现
- 界面层 `src/ui`：Vue 页面与原生 CSS 视图

## 数据备份

顶栏「导出备份」会把当前摄入记录与每日目标打包为带应用标识的 JSON 文件（`information-recipe-backup-YYYY-MM-DD.json`）下载，可用于换设备或清理缓存前的备份。

「导入备份」从文件恢复数据：

- 导入前校验文件是否为本应用导出的格式（非 JSON、其他应用的文件会被拒绝）；兼容没有备份信封的旧版本裸快照
- 旧版本数据缺失字段时按默认值补齐（标题、来源、营养类别、时长、日期、备注、每日目标），整条损坏的记录自动跳过，不报错中断
- 与本地已有记录冲突时弹窗选择：**合并**（保留本地、追加新记录，每日目标保留本地值）或**覆盖**（用备份完全替换），也可取消
- 合并时同时按记录 `id` 与内容指纹（日期+标题+来源+类别+时长+备注）判重，重复摄入记录只保留一份，分钟数不会重复计数；无冲突时直接合入
